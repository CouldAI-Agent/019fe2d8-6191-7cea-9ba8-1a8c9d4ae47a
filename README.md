# تطبيق الصورة الساحرة

تطبيق فلاتر (Flutter) يعرض صورة مبهرة وساحرة مع تأثيرات إضاءة متوهجة وحركات متتالية لتجربة بصرية فريدة. 

## المميزات
- **تأثيرات بصرية مبهرة:** إضاءة متوهجة متحركة حول الصورة.
- **ألوان متدرجة:** خلفية داكنة وجذابة تتناسب مع الأجواء الساحرة.
- **دعم الأجهزة المتعددة:** تصميم متجاوب يعمل على أنظمة الهواتف الذكية (iOS و Android) والويب وأجهزة سطح المكتب.

## خطوات التشغيل
1. تأكد من تثبيت بيئة عمل فلاتر.
2. قم بتشغيل الأمر `flutter pub get` لتثبيت الحزم المطلوبة.
3. قم بتشغيل التطبيق عبر الأمر `flutter run`.
